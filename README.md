# Portfólio de Business Analysis — Healthtech

Artefatos de análise de negócio produzidos a partir de um projeto pessoal: um sistema RIS/PACS para clínicas de diagnóstico por imagem.

O objetivo deste repositório é mostrar **como eu penso um produto**: do problema real da operação até requisitos testáveis que o time de desenvolvimento consegue implementar.

> Dados de clínicas, pacientes e parceiros foram omitidos ou generalizados. Números marcados como premissa estão em validação.
